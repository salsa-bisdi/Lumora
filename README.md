# PAUSE — Home Fragrance Website

Website statis PAUSE dengan HTML, CSS, dan JavaScript murni.

## Struktur
- `index.html` — konten dan struktur website.
- `style.css` — desain desktop, tablet, dan mobile.
- `script.js` — interaksi navigasi.
- `assets/pause-logo.png` — logo resmi PAUSE dari pemilik brand.

## Sebelum dipublikasikan
1. Perbarui informasi kontak setelah nomor WhatsApp dan akun Instagram/Facebook resmi tersedia.
2. Perbarui foto candle dengan foto produk PAUSE yang sebenarnya jika sudah tersedia.
3. Tambahkan aroma, ukuran, harga, dan informasi pemesanan setelah detail produk dikonfirmasi.
4. Periksa seluruh tampilan di perangkat mobile dan desktop.

## Deployment
Unggah isi folder ini ke repository GitHub, lalu hubungkan repository ke Vercel. Entry point website adalah `index.html`.
