PAUSE — PATCH FORM KONSULTASI

Patch ini hanya mengganti index.html dan menambahkan recommendation.html, recommendation.css, recommendation.js.
JANGAN mengganti style.css, script.js, shop.html, shop.js, checkout.html, checkout.js, atau folder assets yang sudah ada.

Pemasangan:
1. Backup index.html yang sekarang.
2. Upload/replace index.html dari ZIP ini di root repository.
3. Tambahkan recommendation.html, recommendation.css, recommendation.js ke root repository.
4. Commit changes ke GitHub; tunggu Vercel deploy.

Alur:
- Tombol di bagian Get in Touch -> recommendation.html (form rekomendasi aroma / custom order).
- Tombol pesan produk pada katalog tetap menuju checkout produk.
- Form konsultasi mengirim ringkasan jawaban ke WhatsApp melalui PAUSE_CONFIG di script.js.

Penting: ganti nomor contoh 6281234567890 di script.js dengan nomor WhatsApp bisnis PAUSE. Tidak ada pembayaran atau order otomatis pada form konsultasi ini.
